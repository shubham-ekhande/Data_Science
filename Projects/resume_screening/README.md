\# 📄 Resume Screening AI



An intelligent Resume Screening and Candidate Ranking system built using 

TF-IDF and BERT-based semantic similarity.



This application analyzes resumes against a given Job Description (JD) 

and ranks candidates based on relevance.



---



\## 🚀 Features



✔ PDF Resume Upload  

✔ Automatic Text Extraction (PyPDF2)  

✔ Text Preprocessing (NLTK)  

✔ TF-IDF Similarity Scoring  

✔ BERT Semantic Similarity Scoring  

✔ Weighted Final Score Calculation  

✔ Skill Matching \& Missing Skill Detection  

✔ Candidate Ranking Dashboard  

✔ Visual Score Comparison Chart  



---



\## 🧠 How It Works



1\. User enters a Job Description.

2\. Uploads one or multiple resumes (PDF format).

3\. System extracts text from resumes.

4\. Text is preprocessed (tokenization, stopword removal).
